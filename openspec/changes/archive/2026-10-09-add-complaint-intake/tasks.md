- [x] 2.3 Add the Structured Output Parser with the JSON schema from the handoff (`reply`, `done`, plus the result fields). Verified a completed test conversation's final turn returns valid JSON matching every field (inspected via `n8nac execution get --include-data`). **Deviation from the handoff's exact shape**: the LLM-facing schema is flat (`reply`, `done`, `label`, `unknownReason`, ... at the top level, not nested under `result`) — nesting `result` as its own required object caused the model to intermittently drop required fields and the parser to silently return `{}` with no error. `Finalize Result` re-nests these into `{ reply, done, result: {...} }` before returning, so the external contract (what `chat.workflow.ts`, and later the test harness, sees) still matches the handoff exactly. Also found and fixed two n8n node-schema traps: `schemaType: 'manual'` uses the `inputSchema` field, not `jsonSchema` (which is a legacy v1.1-only field — the schema was being silently ignored); and `autoFix: true` requires its own `ai_languageModel` connection on the parser node itself, separate from the agent's.
